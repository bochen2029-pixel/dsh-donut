# Contributing

The plugin is not published yet. Issues and design discussion are welcome now. Pull requests against the design record are welcome; pull requests of code wait until the implementation lands.

The canonical design is [`docs/SPEC-v1.md`](docs/SPEC-v1.md). If the spec and the behavior disagree, the behavior wins — open an issue with the session log line that shows it.
